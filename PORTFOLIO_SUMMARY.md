Supply Chain Sentinel – AI-Driven Anomaly Detection Platform

Technologies:
Python, PyTorch, Redis Streams, Docker, Prometheus, Grafana, FastAPI, GitHub Actions

Summary:
Designed and delivered an end-to-end, production-ready ML platform for real-time anomaly detection in supply chain operations. Led system architecture across data ingestion, streaming infrastructure, deep learning model lifecycle, and observability.

Implemented an LSTM Autoencoder–based anomaly detection engine with automatic training, threshold calibration, and persistent model storage. Built a resilient streaming pipeline using Redis Streams and consumer groups, enabling scalable ingestion and inference workflows.

Established full-stack observability with Prometheus and Grafana, exposing model, system, and infrastructure metrics to support operational monitoring and future alerting. Containerized the entire system with Docker and validated CI-ready builds, ensuring portability across local and cloud environments.

The project reflects senior-level ML ownership, emphasizing reliability, maintainability, and operational excellence over experimental modeling.
